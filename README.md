# 21N2 Billiards Related Tools and WebApps

A collection of billiards/pool related tools and web applications.

## 🎱 Pool Scoreboard

A simple, dark-themed scoreboard for tracking pool game scores.

**[Live Demo →](https://brdnwtocode.github.io/21N2-BILLIARDS-RELATED-TOOLS-AND-WEBAPPS/pool-scoreboard/)**

### Features

- Track scores for 2–4 players
- Tap `+` / `−` to increment/decrement scores
- Editable player names (click to rename)
- Running total display with visual "hot" indicator
- Reset all scores, remove players
- Dark/light theme toggle
- Fully responsive — works on mobile

### Usage

Open `pool-scoreboard/index.html` in any browser, or visit the GitHub Pages link above.
